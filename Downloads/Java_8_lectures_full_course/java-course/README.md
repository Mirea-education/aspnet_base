## Код и сквозной пример

Каждая лекция имеет самостоятельную демонстрацию. Можно открыть восьмую, не выполняя предыдущие семь. Учебный магазин связывает темы общей задачей, но цены и ограничения каждого эксперимента заданы в его разделе. Финальный сервис резервирует товар и создаёт заказы. Оплата из лекции 2 изучается отдельно и не является реальной платёжной интеграцией.

## Версии и дополнительные демонстрации

Документационная база курса — Java SE 25. Основные программы собираются с `--release 17` и фактически проверены на OpenJDK 17.0.20. Дополнительные программы `bonus25` требуют JDK 25 и не используют preview-возможности. Их запуск в среде подготовки не подтверждён, поскольку JDK 25 там не было. Для них предусмотрена отдельная команда предварительной проверки.

```bash
java tools/Run.java bonus25
```

JDBC-исходники скомпилированы. Для проверки работы с настоящей PostgreSQL нужны сервер и драйвер, которые не входят в архив. Все восемь основных демонстраций запускаются без них.

## Схемы и Git

В комплекте 17 UML-схем в PNG и SVG, а также редактируемые исходники PlantUML. Представлены варианты использования, классы, объекты, состояния, деятельность, последовательности, пакеты, компоненты и развёртывание. PNG встроены в Markdown обычными относительными ссылками, поэтому для их показа не требуется Mermaid или доступ к серверу PlantUML.

Сохраняйте структуру каталогов при загрузке в Git. Откройте `README.md` в просмотрщике репозитория, затем перейдите к лекции. Возможность показа изображений и пользовательских HTML-якорей зависит от площадки. Все изображения можно открыть отдельно по ссылке, а идентификатор блока найти поиском по тексту.
