# Официальные источники курса

Документационная база проверялась 11 октября 2026 года. Для Java ссылки закреплены на версии 25, а для дополнительной БД — на PostgreSQL 17. Исторические инженерные кейсы сохраняют собственный контекст версии и нагрузки.

В лекциях техническое положение сопровождается ссылкой на тематический первоисточник. Формулировки, объяснения, данные и программные примеры созданы для учебного комплекта. Числа результатов выводятся из приведённых входных данных либо взяты из фактического запуска, который указан в отчёте проверки.

Ссылки ведут на спецификации, API и руководства издателей технологий. Netflix и Uber включены как официальные инженерные публикации самих компаний. Их наблюдения не выдаются за текущие универсальные характеристики Java.

## Как проверять спорное утверждение

1. Уточните версию платформы и найдите ссылку в том же блоке лекции.
2. Для правила языка откройте JLS, для поведения метода — API конкретного типа.
3. Сравните полный договор, включая исключения, ограничения и примечания о реализации.
4. Запустите минимальный пример. Его результат показывает конкретное наблюдение, но не заменяет общий договор спецификации.

Список ссылок не является обещанием неизменной доступности внешних сайтов. Внутренние материалы курса и основные демонстрации работают без интернета. Оригинальные страницы документации в архив не копировались.
