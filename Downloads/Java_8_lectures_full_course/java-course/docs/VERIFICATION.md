# Проверка комплекта

Проверка выполнена 11 октября 2026 года. Этот файл отделяет фактически выполненные проверки от дополнительных лабораторных работ, для которых нужна другая среда.

## Среда

Основной маршрут проверен на OpenJDK 17.0.20 в Linux. Исходники компилировались с `--release 17` средствами JDK. Для запуска использовался включённый в комплект `tools/Run.java`. Сторонние зависимости для основных демонстраций не требовались.

Документационная база курса — Java SE 25. Возможности, требующие именно JDK 25, вынесены в дополнительные демонстрации и отмечены в лекциях. Их фактический запуск в среде подготовки не выполнен.

## Документы и схемы

- В папке `lectures` находятся ровно 8 Markdown-файлов лекций.
- В папке `speaker-notes` находятся ровно 8 соответствующих сценариев преподавателя.
- Все 66 идентификаторов блоков и их порядок совпадают в каждой паре файлов.
- Проверены относительные ссылки на локальные файлы, изображения и якоря.
- Для 17 схем имеются PNG, SVG и исходники PlantUML.
- SVG проверены как XML, изображения отрисованы и визуально просмотрены.
- В комплект входят 26 Java-файлов, включая средство запуска, тесты и дополнительные демонстрации.

SVG подготовлены как самостоятельные изображения по тем же моделям, которые представлены в PlantUML. Исходники PlantUML не проходили через движок PlantUML в среде подготовки. При самостоятельном рендеринге расположение элементов может отличаться от PNG и SVG.

## Границы проверки

Дополнительные демонстрации `bonus25` не запускались, поскольку JDK 25 в среде подготовки отсутствовал. Перед показом выполните их на подготовленном компьютере преподавателя.

JDBC-код скомпилирован, но интеграция с настоящей PostgreSQL не выполнялась. Сервер PostgreSQL и JDBC-драйвер не входят в комплект. Порядок настройки и отдельная таблица ожидаемых результатов находятся в [лабораторной работе JDBC](JDBC-LAB.md). Проверка демонстрации без настроек подключения не заменяет проверку транзакций с БД.

Команды PowerShell приведены для самостоятельного запуска в Windows и в среде подготовки не выполнялись. Команды записи и анализа JFR в лекции 8 объяснены по официальной документации, но отдельная запись JFR при подготовке не создавалась.

Показ Markdown на конкретной Git-площадке пользователя не проверялся. Изображения подключены относительными ссылками на PNG. Идентификаторы блоков остаются доступными для поиска даже в просмотрщике, который не поддерживает пользовательские HTML-якоря.

## Повторить перед занятием

Запустите из корня распакованного проекта.

```bash
java --version
java tools/Run.java all
java tools/Run.java test
java tools/Run.java metadata
java tools/Run.java jar
java -jar build/orders.jar
java --module-path build/orders.jar -m course.orders/course.orders.app.DemoMain
```

Для дополнительных возможностей Java 25 используйте отдельную команду на JDK 25.

```bash
java tools/Run.java bonus25
```

Для демонстрации API откройте отдельный терминал.

```bash
java tools/Run.java server
```

Запросы к API приведены в [краткой инструкции](QUICKSTART.md) и [контракте API](API-CONTRACT.md). Для завершения сервера нажмите `Ctrl+C`.

Собранные классы, JDK, JDBC-драйвер, временные данные тестирования и промежуточные файлы подготовки в распространяемый ZIP не включены. При первом запуске `tools/Run.java` создаёт каталог `build` самостоятельно.
