В объектной схеме контексты локальных переменных показаны как поясняющие объекты модели, а не как утверждение о физическом размещении данных JVM. Схемы деятельности показывают выбранные предметные ветви и не обязаны перечислять каждое техническое исключение.

[Спецификация UML 2.5.1](https://www.omg.org/spec/UML/2.5.1)
